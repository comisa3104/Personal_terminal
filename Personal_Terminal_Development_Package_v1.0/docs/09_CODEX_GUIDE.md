# 09 — Codexへの指示の渡し方
Version: 1.0

## 結論
Codexには長い会話を毎回説明するのではなく、
`AGENTS.md` と `docs/07_TASKS.md` を読ませて「今回の1タスク」を実装させる。

---

## 1. 配置
Personal Terminalのコードが入っているフォルダの最上位に `AGENTS.md` を置く。

例:

```text
personal-terminal/
├─ AGENTS.md
├─ index.html
├─ css/
├─ js/
└─ docs/
```

Codexは作業対象フォルダ内のプロジェクト指示を参照できるため、AGENTS.mdを継続ルールとして使う。

---

## 2. 最初のCodex指示
最初は「実装」より先に、現状調査をさせる。

### 推奨プロンプト
```text
Personal Terminal v1.1の開発を開始します。

最初にAGENTS.mdとdocs内のMarkdownを確認してください。
今回は docs/07_TASKS.md の PT-001 だけを実施してください。

まだ大きなコード変更はしないでください。
現状構造を確認し、
1. 主要ファイル
2. 各ファイルの役割
3. 現在の主要機能
4. User Modeを導入する候補箇所
5. リスク
6. 次のPT-002実装手順
を日本語で報告してください。
```

---

## 3. Codexから結果が返った後
人間が確認する。

### 確認すること
- v1.1を勝手に大幅変更していないか
- ファイルを勝手に削除していないか
- こちらが依頼していない機能を追加していないか
- 説明が理解できるか
- 次の作業が1つに絞られているか

分からない場合は、Codexへそのまま進めさせずChatGPTへ結果を貼って整理する。

---

## 4. 実装を依頼する時
PT-002を確定した後、`07_TASKS.md`を書き換える。

### 推奨プロンプト
```text
AGENTS.md と docs/07_TASKS.md を確認してください。

PT-002だけを実装してください。
今回の範囲外の改善は行わないでください。
Personal Terminal v1.1の既存動作を維持してください。

実装後はAGENTS.mdのCompletion Report Formatに従って、
変更ファイル、変更内容、動作確認、既存機能への影響、
未解決事項、次の推奨作業を日本語で報告してください。
```

---

## 5. 修正依頼
「何か変」ではなく、現象を書く。

悪い例:
```text
うまく動かないので直してください。
```

良い例:
```text
PT-002の実装後、設定画面でSeniorを選択し、
ページを再読み込みするとStandardへ戻ります。

期待する動作:
再読み込み後もSeniorが維持される。

この問題だけを調査・修正してください。
他のUI変更は行わないでください。
```

---

## 6. 1回の依頼サイズ
原則:
- 1つの機能
- 1つの不具合
- 1つのリファクタリング目的

を1タスクとする。

避ける:
```text
モード切替、音声、AI、クラウド、デザイン変更を全部実装してください。
```

推奨:
```text
今回はUser Modeの保存と読み込みだけ実装してください。
```

---

## 7. CodexとChatGPTの役割分担

### ChatGPT
- アイデア整理
- 要件定義
- 仕様比較
- TASKS.md作成
- Codex結果の説明
- 次の作業判断

### Codex
- コード調査
- ファイル編集
- 実装
- テスト
- 差分確認
- 技術的な修正

### 人間
- 目的決定
- UI確認
- 実機確認
- 採用/却下の判断

---

## 8. トラブル時の停止プロンプト
```text
ここで実装を止めてください。
これ以上変更しないでください。

現在までに変更したファイルと変更内容を一覧化し、
元に戻す場合に必要な手順を説明してください。
```

---

## 9. 完了確認プロンプト
```text
このTaskの完了条件をdocs/07_TASKS.mdと照合してください。

未達項目があれば実装せず、未達項目だけ報告してください。
すべて満たしている場合は、
動作確認結果と残存リスクを報告してください。
```

---

## 10. 毎回の基本形
迷った場合は次の4行でよい。

```text
AGENTS.mdを確認してください。
docs/07_TASKS.mdを確認してください。
今回のTaskだけを実施してください。
範囲外の変更をせず、実施後に日本語で結果を報告してください。
```
