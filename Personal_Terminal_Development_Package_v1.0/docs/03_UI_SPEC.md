# 03 — UI SPEC
Version: 1.0

## General HCI Principles
- 「何ができるか」が画面を見て理解できる
- 重要操作を上部または中央に置く
- 1画面に情報を詰め込みすぎない
- 操作後の結果を明確に表示する
- 誤操作から戻れる
- モバイル・タッチ操作を優先する

## Standard Mode
現行Personal Terminal v1.1のUIを基準とする。

## Kids
- 大きめのボタン
- 難しい用語を避ける
- 「タスク」→「やること」等に置換可能
- 学習を促すが、答えを一方的に与える設計にしない

## Junior
- 宿題・提出物・部活・テストを中心にする
- 自己管理を支援する

## Student
- 学習計画・模試・進路・受験を扱える余地を持つ
- Kidsより情報密度を上げる

## Senior
- 大きな文字
- 大きな操作対象
- 機能数を絞る
- 音声中心でも画面表示を併用する
- 重要操作は確認を挟む
- 「困った」「戻る」を分かりやすくする

## Responsive Direction
- iPad landscape：基準レイアウト
- iPhone portrait：縦1列またはカード再配置
