# 04 — USER MODES
Version: 1.1

## Common Rule
User ModeはUIだけでなく表示語彙・情報量・AI介入方法を切り替える設定。

## standard
一般利用者。
- 今日の予定
- 今日のタスク
- Activity
- AI相談
- 設定

## kids
小学生。
- きょうのよてい
- やること
- しゅくだい
- じかんわり
- AIにきく
AIは答え代行より考え方・習慣形成を支援。

## junior
中学生。
- 宿題/提出物
- 部活
- テスト
- 学習支援

## student
高校生。
- 学習計画
- 模試
- 志望校
- AI学習支援

## senior
高齢者。
- 今日の予定
- 重要なやること
- 家族
- 音声
- 簡易設定
AIは短文・復唱・確認を重視。

## Priority
1. standard
2. mode foundation
3. senior pilot
4. voice foundation
5. student
6. junior
7. kids
