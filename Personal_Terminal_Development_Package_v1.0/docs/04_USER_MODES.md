# 04 — USER MODES
Version: 1.0

## Common Rule
User ModeはUIだけでなく、表示語彙・情報量・AIの介入方法も切り替えるための設定である。

## standard
### Target
一般利用者

### Main Areas
- 今日の予定
- 今日のタスク
- Activity
- AI相談
- 設定

## kids

- じかんわり
- AIにきく
