# 01 — REQUIREMENTS
Version: 1.0

## A. Core Requirements

### A1. Schedule
- 今日の予定を表示できる
- 予定を追加できる
- 予定を編集できる
- 予定を削除できる
- 時刻と内容を保持できる

### A2. Tasks
- 今日のタスクを表示できる
- タスクを追加できる
- 完了・未完了を管理できる
- 必要に応じて編集・削除できる

### A3. Activity / Learning
- 今日取り組む活動を表示できる
- 目標時間を設定できる
- 実施時間を記録できる
- 将来は「学習」以外にも利用可能な汎用構造を目指す

### A4. AI Support
- 「今日を整理」できる
- 「空き時間を使う」提案ができる
- 「一日を振り返る」支援ができる
- 将来は利用者モードに応じてAIの説明・介入レベルを変える

### A5. Settings
- 配色を選べる
- User Modeを選べる
- 将来、文字サイズ・音声・簡易UI設定を追加できる

### A6. Data
試作段階ではローカル保存を基本とする。
将来の複数端末同期や家族共有は別フェーズで検討する。

## B. Non-Functional Requirements
- 非エンジニアでも扱いやすい
- iPad横向きで使いやすい
- iPhone縦向きにも対応可能な設計
- 文字が小さすぎない
- 主要操作が過度に深い階層にならない
- 既存機能を壊さず段階的に改良できる
- PWA化を妨げない

## C. Out of Scope for Current Foundation Phase
- 本番クラウドDB
- 本番ユーザー認証
- 課金
- 実際の保護者アカウント連携
- 実際の家族アカウント連携
- AI APIキーの本番埋め込み
