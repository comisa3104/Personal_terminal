# PT-001 — Personal AI Terminal 1.1 基準版の一次調査

確認日: 2026-09-18

## 結論と資料の位置づけ

- [公開版](https://personal-terminal-wireframe.skomy3810155.chatgpt.site/) は画面上「Personal AI Terminal 1.1」と表示される。これを動作基準とする。
- `app/` は公開サイトから取得した HTML、manifest、Service Worker、アイコンの保全用スナップショット。元の開発ソースを取得したものではない。配信時のホスティング用スクリプトは除去した。
- `docs/` は設計・作業指示の正本。`Personal_Terminal_Development_Package_v1.1_CrossPlatform/` は同内容の配布用コピーとして当面固定する。
- `app/` を GitHub に保存しても公開サイトは自動更新されない。公開版の変更は別途 Sites 側で行う。

| ファイル | 役割 |

実装済み: 今日の予定の追加・編集・削除、タスクの追加・編集・完了・削除、学習テーマと時間記録、3つの定型整理メニューと自由入力のルールベース応答、6配色、端末内自動保存、JSON書き出し・読込み、PWA設定。

未実装: 生成AI API接続、ログイン、端末間自動同期、外部カレンダー連携、User Mode。画面上の「AI相談」は生成AIとの会話ではない。

## クロスプラットフォーム一次監査

- CSSにスマートフォン向けの幅による切替と、広い画面の2列配置がある。viewport、safe-area用CSS、Service Worker登録、manifestを確認した。
- タッチ操作はボタン中心。各ボタンの実際の押しやすさ、文字サイズ、縦横回転、ソフトキーボード表示時の操作は未検証。
- Safari/iPhone、Safari/iPad、Chrome/Androidスマートフォン、Chrome/Androidタブレット、Windowsブラウザでの実機確認は未完了。
- 音声・通知APIは未実装。Android専用コードは不要と判断する段階ではない。
- オフライン用キャッシュはあるが、更新直後の旧画面表示や端末上でのバックアップ操作は未検証。

## PT-001 の残作業と PT-002 推奨手順

1. iPadとiPhoneで予定・タスク・学習、配色、再起動後の保存、JSONバックアップ・復元を確認する。Androidスマートフォンとタブレットでも同じ手順を行う。
2. 旧1.0データが残る端末では、先にJSONを書き出してから1.1を開き、利用者が追加したデータが維持されるか確認する。試験用データで行う。
3. `docs/11_TEST_MATRIX.md` に端末、OS、ブラウザ、結果、問題点を記録する。特にオフラインと画面の更新を確認する。
4. PT-001 が完了したら PT-002 を1件として確定する。`userProfile.mode` の初期値を `standard` とし、既存の配色設定と保存データを保ったまま設定項目だけを追加する。画面のモード別変更は次のTaskに分ける。
5. Standardが従来通り動くことを実機で確認した後、Senior Modeの最小試作へ進む。音声やKids/Junior/Studentはさらに後段とする。

公開中のサイトを変更・再公開する前に、本人が実機で確認する運用方針を維持する。
